# Financial Summary 可用版本

继续已确认的 React + Firebase 个人财务方案。在原项目直接实现，无 Git 仓库。界面用中文，默认 USD；所有金额用整数美分保存，日期按本地日历。

本次交付：月度收入、净支出（支出减退款）、净现金流；转账/信用卡还款不计收入支出；六个月趋势和支出分类；交易、账户余额、固定支出的新增/编辑/删除；按账户当前手动余额计算资产/负债/净资产；固定计划只作预算展示，不能重复计入实际支出。交易不会自动调整账户余额，界面明确余额是手动快照。

未配置 Firebase 可用独立本地工作区，数据只存本浏览器。示例数据只通过明确的演示入口加载到内存，不写入本地或云端。支持交易 CSV 导出。Google 登录后订阅 users/{uid} 下 transactions/accounts/recurring_payments。云端出错显示错误，不能默默改用本地数据。真实账户云端不自动导入本地或演示数据。

Firebase 规则同时限制路径 UID 和 config/access 文档里的 ownerUid；config/access 只能由控制台管理员设置，客户端不可读写。规则校验金额、类型、必需字段。前端不接收 Admin 私钥。不部署到云端，真实连接等待项目公开配置和 UID。当前不需要 Storage。

PDF 自动导入需要用户账单样本来验证布局、退款和还款，保留后续事项，界面不提供虚假上传。过去提到的净资产历史和汇总缓存稍后在真实数据稳定后接入，本版本从原始记录即时计算。

验收：本地首次空白，演示标识清楚；新增收入后对应月份数字变化且刷新保留；编辑/删除可用；负债正确扣除；固定计划不增加实际支出；金额输入拒绝无效/超过两位小数；失败写入不宣称保存；移动端可使用；测试、类型/构建、lint 和浏览器交互检查通过。
